About this dashboard


    

      
      

        Once a day, a small program signs in to HubSpot and counts up each rep's activity
        (calls, emails, texts, chats, and tasks) for that day. It saves those counts to a
        plain data file that this page reads — so the page itself never has to contact
        HubSpot directly. That keeps things simple, free to host, and easy on HubSpot's usage limits.
