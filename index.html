About this dashboard


    

      
      

        This page can show three different reports — Sales Activities,
        Bulk Orders, and Team Store — switchable from the
        Report dropdown above the date filters. Right now, while the production
        HubSpot connection is still being set up, the numbers are brought in from the company's
        exported sales reports rather than pulled live. A small program converts each export into
        the plain data file this page reads, so the page itself stays simple, free to host, and
        easy on HubSpot's usage limits. (A daily automatic HubSpot pull is already running quietly
        in the background and will take over once production access is ready.)

How to read this page

    

      
    
        
  1. Choose a report from the Report dropdown — Sales Activities, Bulk Orders, or Team Store.
    2. 
        
  2. Pick a date range — Today, Yesterday, This Week, a custom range, etc.
    3. 
        
  3. The summary boxes and table below add up that rep's numbers for the days in that range.
    4. 
        
  4. Click any number — in a summary box, the table, or a Top Performers chart — to jump straight into the team's HubSpot reports dashboard in a new tab. (HubSpot doesn't support linking directly to a pre-filtered view, so once you're there, use HubSpot's own Owner and Date filters to zoom in on the rep and day you're after.)
    5. 
        
  5. Click any column header to sort by it, or use Export CSV to download the table as a spreadsheet.
    6. 
        
  6. Refresh reloads the saved data file in case it was updated since you opened the page.
    7. 
      

    


    


    
Definitions

    

      
Sales Activities

      
    
        
  • Pipeline Touch — calls the rep logged.
    • 
        
  • Emails Sent / Received — outgoing and incoming emails logged on records.
    • 
        
  • SMS Sent / Received — text messages logged.
    • 
        
  • Chats Engaged — chat conversations the rep took part in.
    • 
        
  • Tasks Created / Completed — tasks the rep created, and tasks they marked done, in that period.
    • 
      


      
Bulk Orders

      
    
        
  • Quotes Created / Value — number of bulk quotes started, and their combined dollar value.
    • 
        
  • Quotes Committed — quotes the customer agreed to move forward with.
    • 
        
  • Closed Lost Deals — bulk deals that didn't close.
    • 
        
  • Bulk Conversions — quotes that turned into actual orders.
    • 
        
  • Bulk Revenue — dollar amount of bulk orders written.
    • 
        
  • Bulk Orders Written — number of bulk orders placed.
    • 
      


      
Team Store

      
    
        
  • Build Requests — new online team store setup requests.
    • 
        
  • Went Live — stores that finished setup and opened.
    • 
        
  • Stores w/ Revenue — open stores that have brought in sales.
    • 
        
  • Gross Revenue — total sales from open team stores.
    • 
        
  • Open Stores w/ Revenue / No Revenue — how many open stores have, or haven't yet, generated sales.
    • 
        
  • TS Transactions — number of orders placed through team stores.
